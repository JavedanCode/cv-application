# CV Application Creator

A modern React-based CV/Resume builder that allows users to create and preview their resume in real time.

## Live Demo

🔗 https://javedancode.github.io/cv-application/

---

## Features

- Real-time resume preview
- Personal information section
- Education section
- Experience section
- Responsive layout
- Modern dark theme UI
- Built with reusable React components
- State management using React Hooks

---

## Built With

- React
- Vite
- JavaScript (ES6+)
- HTML5
- CSS3

---

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/JavedanCode/cv-application.git
```

### Navigate to the Project

```bash
cd cv-application
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

---

## Build for Production

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
